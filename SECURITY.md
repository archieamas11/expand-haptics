# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

You may contact the maintainer through:

* **Website:** [albarico.is-a.dev](https://albarico.is-a.dev/#contact)
* **GitHub Issues:** Use this repository’s Issues tab if public disclosure is acceptable

Please include as much detail as possible, such as:

* A clear description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Screenshots, logs, or proof-of-concept code (if available)

All reports will be reviewed as quickly as possible, and appropriate action will be taken to
investigate and resolve verified issues.
